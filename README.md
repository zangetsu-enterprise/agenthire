# AgentHire

Find Vetted AI Agencies & Automation Consultants. A directory of 20 verified AI agencies.

**Live demo:** [https://chachi-agenthire-quqkdeduj-carlosreyesafks-projects.vercel.app](https://chachi-agenthire-quqkdeduj-carlosreyesafks-projects.vercel.app)

## Stack

- HTML5, CSS3, JavaScript (vanilla)
- 100% frontend — no build step, no backend
- Deployed on Vercel

## Run locally

```bash
# Serve the src/ directory with any static server
npx serve src/
# or
python3 -m http.server -d src/ 8000
```

Then open http://localhost:8000 (or :3000 for npx serve).

├── ...           # Additional pages & assets
